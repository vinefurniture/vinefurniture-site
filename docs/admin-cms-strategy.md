# Vine Furniture Admin / CMS Strategy

## 목표
바인퍼니처 운영자가 개발 지식 없이도 **자주 바뀌는 정보만 안전하게 수정**할 수 있게 하는 것입니다.

특히 아버님처럼 PC 숙련도가 높지 않은 경우에는, 일반적인 Git 기반 CMS 전체를 그대로 노출하는 것보다
**실수 가능성이 낮은 간편 관리 범위만 제한해서 제공하는 방식**이 훨씬 적합합니다.

---

## 핵심 원칙
1. **자주 바꾸는 것만 노출**
2. **망가질 수 있는 것은 숨김**
3. **사진은 자리(slot) 기준으로 교체**
4. **저장과 반영을 분리**
5. **텍스트는 큰 입력칸 + 한글 라벨 중심**

---

## 관리자에게 열어주기 좋은 범위

### A. 바로 열어줘도 되는 항목
- 대표 전화번호
- 운영시간
- 주소
- 메인 제목/소개문
- 문의 페이지 문구
- 외부 링크(인스타그램, 블로그, 네이버 플레이스)
- 대표 사진 3장
  - 메인 대표 사진
  - 소파 대표 사진
  - 매장 전경 사진
- 갤러리 사진 순서 변경
- 갤러리 사진 추가/숨김

### B. 조건부로 열어줄 항목
- 공지 배너 on/off
- 휴무일 임시 안내
- 시즌별 대표 문구 교체
- 추천 제품 3개 노출 여부

### C. 관리자에게 숨기는 것이 좋은 항목
- 헤더/푸터 구조
- 레이아웃, 색상, 간격
- SEO 세부 메타 구조
- favicon / manifest / sitemap
- 배포 설정(Vercel)
- 파일명 규칙과 실제 public 경로

## 추천 운영 모델

### 1단계: 저위험 간편관리 (가장 추천)
**대상:** 아버님이 직접 관리

- 텍스트 10~15개 필드만 수정 가능
- 사진은 "자리별 교체"만 가능
- 갤러리는 드래그 정렬만 가능
- 저장 후 미리보기
- 확인 후 "사이트 반영"

이 단계가 가장 현실적입니다.
전체 CMS처럼 모든 페이지를 자유편집하게 하면 오히려 실수가 늘어날 가능성이 큽니다.

### 2단계: 확장 관리
**대상:** 가족/실무 보조자

- 카드 섹션 추가/삭제
- 브랜드 소개 문구 추가
- 공지/프로모션 배너 관리
- 갤러리 카테고리 관리

### 3단계: 개발자 전용 관리
- 디자인 변경
- 구조 개편
- SEO 고급설정
- 도메인/배포/성능 최적화

## 기술 추천

### 권장 방향
**커스텀 간편 관리자 페이지 + 단순 데이터 저장 구조**

이 프로젝트는 정적 Astro 사이트이므로, 최종적으로는 다음 중 하나가 현실적입니다.

#### 옵션 A. 커스텀 `/admin` + 단순 JSON 저장 구조
- 장점: UI를 아버님 기준으로 아주 단순하게 설계 가능
- 장점: 필요한 필드만 보여줄 수 있음
- 단점: 저장용 백엔드/서버리스 작업이 추가로 필요

#### 옵션 B. Git 기반 CMS(Decap CMS 등)
- 장점: 구현 속도는 빠름
- 장점: 정적 사이트와 궁합이 좋음
- 단점: GitHub 로그인/커밋 개념이 운영자에게 어렵게 느껴질 수 있음

#### 옵션 C. 외부 폼형 CMS/노코드 도구
- 예: Airtable, Notion, Sanity, Storyblok
- 장점: 비개발자 편집성이 좋을 수 있음
- 단점: 운영 비용/권한관리/한글 UX/사진 업로드 흐름을 별도 검토해야 함

### 현재 추천 결론
바인퍼니처는 **옵션 A(간편 관리자 페이지)** 가 가장 적합합니다.
이유는:
- 수정 범위가 작고 명확함
- 아버님용으로 버튼과 흐름을 한국어 중심으로 단순화 가능
- Git/GitHub 개념을 숨길 수 있음
- 사진 교체를 "슬롯형"으로 안내 가능

## 데이터 구조 원칙
현재는 `src/data/site-content.json` 중심으로 텍스트를 모으고,
`src/data/site.ts` 에서 실제 화면 바인딩과 이미지 매핑을 담당하도록 정리했습니다.

이 구조는 이후 다음 방향으로 확장하기 쉽습니다.
- 텍스트 수정 → JSON 저장
- 대표 사진 교체 → 지정 슬롯 경로 갱신
- 갤러리 순서 변경 → 배열 순서 변경

즉, 지금 구조는 향후 CMS 연결을 위한 중간 단계로 적절합니다.

## 관리자 UX 가이드

### 필수 화면 1: 오늘 자주 바꾸는 정보
- 전화번호
- 운영시간
- 주소
- 휴무 안내

### 필수 화면 2: 메인 화면 관리
- 메인 제목
- 소개문
- 대표 버튼 문구
- 메인 대표 사진

### 필수 화면 3: 갤러리 관리
- 사진 썸네일 목록
- 순서 변경
- 숨김/노출 토글
- 사진 교체

### 필수 화면 4: 미리보기 / 반영
- 저장
- 미리보기 열기
- 사이트 반영

### UX 디테일 권장
- 큰 글씨와 큰 버튼
- 전문용어 금지
- "OG", "slug", "canonical" 같은 용어 숨김
- "저장 완료", "사진 교체 완료" 같은 즉시 피드백
- 한 화면에 너무 많은 입력칸 배치 금지

## 결론
아버님이 직접 관리하실 사이트라면,
**“무엇이든 수정 가능한 CMS”보다 “꼭 필요한 것만 수정 가능한 간편 관리자”가 훨씬 좋은 선택**입니다.

추천 범위는 아래까지입니다.
- 전화번호 / 운영시간 / 주소
- 메인 문구
- 대표 사진 3장
- 갤러리 순서 및 노출
- 문의/오시는 길 안내문

그 이상(레이아웃, SEO, 배포, 디자인)은 개발자 영역으로 남기는 것이 안전합니다.

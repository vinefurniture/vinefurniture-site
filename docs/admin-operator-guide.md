# 바인퍼니처 관리자 사용 매뉴얼

이 문서는 바인퍼니처 운영자가 `/admin` 화면을 사용할 때 필요한 **가장 짧은 실사용 순서**만 정리한 안내서입니다.

## 1. 어디서 여나요?
- 관리자 화면: `/admin`
- 빠른 안내 페이지: `/admin-guide`
- 미리보기: `/`, `/location`, `/contact` 에서 `?draft=1` 자동 반영

## 2. 이 화면에서 바꿀 수 있는 것
- 대표 전화
- 운영시간
- 주소
- 방문 안내 제목 / 안내문 / 혜택 문구
- 메인 / 오시는 길 / 문의 문구
- 인스타그램 / 블로그 / 네이버 플레이스 링크
- 현재 사용 중인 대표 사진 3장
- 최근 사진 영역은 사이트 관리자 대신 인스타그램에서 관리

## 3. 가장 쉬운 기본 사용 순서
1. `/admin`을 연다
2. **1~3번 항목만 먼저 본다**
3. 전화번호 / 운영시간 / 주소를 먼저 확인한다
4. 방문 안내, 방문 혜택과 메인 / 오시는 길 / 문의 문구를 수정한다
5. 상단의 미리보기 버튼으로 실제 화면을 확인한다
6. 문제 없으면 JSON 파일을 내보낸다

## 4. 보통은 안 펼쳐도 되는 항목
- 인스타그램 / 블로그 / 네이버 플레이스 링크
- 현재 사용 중인 대표 사진 3장
- 최근 사진은 사이트 관리자 대신 인스타그램에서 관리

필요할 때만 아래 접힌 항목을 펼쳐 수정하면 됩니다.

## 5. 문구만 바꿨을 때
문구 / 링크만 바꿨다면:

1. `문구 파일 저장` 클릭
2. `vine-admin-publish.json` 저장
3. 유지보수자가 아래 명령으로 반영

```bash
npm run admin:import -- ./vine-admin-publish.json --write
npm run build
npm run preview:check
```

## 6. 대표 사진도 바꿨을 때
중요: 관리자 화면에서 사진을 올리면 **우선 이 브라우저에서만 임시 저장**됩니다.

대표 사진까지 실제 사이트에 반영하려면 아래 순서를 사용합니다.

1. `사진 파일 저장` 클릭
2. `vine-admin-draft.json` 저장
3. 유지보수자가 아래 명령 실행

```bash
npm run admin:extract-assets -- ./vine-admin-draft.json --write
```

4. 그러면:
   - 업로드한 대표 사진이 `public/images/vine/...` 경로에 실제 파일로 저장됨
   - 같은 위치에 `vine-admin-publish.json`이 자동 생성됨
5. 그 다음 유지보수자가 아래 명령으로 사이트 내용 반영

```bash
npm run admin:import -- ./vine-admin-publish.json --write
npm run build
npm run preview:check
```

## 7. 최근 사진 관리 방법
- 홈의 최근 사진 영역은 인스타그램 공식 피드를 그대로 보여줍니다.
- 따라서 사이트 관리자에서 최근 사진 순서/숨김을 따로 바꾸지 않습니다.
- 최근 사진을 바꾸려면 인스타그램 계정에서 게시물을 관리하면 됩니다.

## 8. 꼭 기억할 점
- 저장은 자동으로 됩니다
- 평소에는 **1~3번 항목만 수정**해도 충분합니다
- `처음 상태로 되돌리기`를 누르면 이 브라우저 초안이 지워집니다
- 사진을 바꾼 경우에는 `문구 파일 저장`만으로는 실제 사이트 사진이 바뀌지 않습니다
- 사진 변경이 있으면 반드시 `사진 파일 저장`도 함께 해야 합니다

## 9. 유지보수자 최종 확인
반영 후 아래를 확인합니다.
- 메인 페이지
- 최근 사진 확인용 홈 메인 페이지
- 오시는 길 페이지
- 문의 페이지
- 전화 링크 / 외부 링크 / 대표 사진 반영 여부
